# 개요
기존 UI 그래픽 요소는 유지하되, 레이아웃과 페이지 구성의 변경이 이전부터 요구되어 왔다. 이를 구체화 하고 구현하고자 한다.

# 구상 중인 레이아웃
### 내비게이션 바 (BottomNav.jsx)
##### 현행
| 홈 | 주유 | 정비 | 기타
##### 개정안
| 홈 | 기록 | 설정

### 홈 (Home.jsx)
##### 현행
-----
| 프로필사진 | "환영합니다" | 설정 버튼 |
-----
| 번호판 | 차종-연식-차급-연료 |
-----
| "한 달 동안 n 원 지출" |
| "평균 연비 n Km/L" |
| "총 주행거리 n Km" |
-----
| 최근 기록 |
| 주유 ~~~ |
| 정비 ~~~ |
| 기타 ~~~ |
##### 개정안
-----
| 프로필사진 | 번호판-차종-연식-차급-연료 | (<-- 번호판의 디자인 요소를 폐지하고 차종 등 평문 표기에 통합)
-----
| "한 달 동안 n 원 지출" |
| 평균 연비 n Km/L |
| 총 주행거리 n Km |
-----
| 최근 기록 |
| (구분 없이 최신순으로 최대 10개까지 표시) |

### 기록 (주유, 정비, 기타 통합)
##### 현행
-----
| "(주유 or 정비 or 기타) 기록" |
| (기록 페이지) |
-----
| (더하기 버튼) |
-----
##### 개정안
-----
| 주유 | 정비 | 기타 | (<-- 이들 중 하나를 선택하면 해당하는 항목만 표시함. 동시에 하나만 활성화 가능하고, 다시 탭하면 원래대로 전체 기록이 보여짐. 또한 이는 필터 기능의 MVP 모델. 지금은 이것만 구현.)
| (기록 페이지) |
-----
| (더하기 버튼) |

### 기록 양식 (주유, 정비, 기타 통합) (더하기 버튼 누르면 나오는 페이지)
##### 개정안
기존의 주유, 정비, 기타 기록 양식을 그대로 구분하되, 기록 페이지 개정안의 '주유-정비-기타' 탭과 같은 모양으로 상단에 선택지가 나타남. 기본적으로 주유 탭이 활성화 되지만, 정비 또는 기타 항목을 탭하여 양식을 불러올 수 있음. 입력하다 말고 다른 탭을 누르면 입력 중인 항목을 버리고 가도 될지 확인해야 함.
