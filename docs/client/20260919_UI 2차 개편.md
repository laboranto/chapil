## 레이아웃 전면 개편
### BottomNav
- 이곳에는 더 이상 관행대로 버튼을 배치하지 않는다. 전부 폐기한다.
- 폐기 후 빈 자리에는 '기록' 페이지에 존재했던 '+' 버튼을 이곳으로 끌어온다. --> 버튼을 정중앙에 배치한다.
### 디자인 토큰
- 기존에 자체 구현했던 디자인 토큰을 폐기한다.
- OS 종류를 파악하여 Material Design, Apple LiquidGlass 테마를 입히며, 데스크탑의 경우 macOS를 제외한 나머지는 일단 KDE Plasma Breeze 테마로 fallback 한다.
- 테마별로 레이아웃을 다르게 배치하는 건 나중 일. 일단 레이아웃은 한 가지만 정하고, 테마 입히는 것만 구성해보자.
### 메인 페이지 | 홈, 기록 통합
- 기존의 홈 페이지의 요약 카드는 상단 고정 형식으로 변경. 스크롤 하면 상단에 고정되면서 height가 줄어들며 표시 내용이 축약됨.
- 나머지는 기존의 기록 페이지처럼 무한 스크롤 페이지네이션 유지.
### 팝업 페이지
